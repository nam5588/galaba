# PRD: 수강 & 학업

- 문서 상태: 초안 (구현 전)
- 작성일: 2026-10-03
- 제품: UniMate (유학생 행정비서)
- 담당 영역: 수강 요건·학업 진척 확인

## 1. 배경과 문제

외국인 유학생은 졸업까지 필요한 학점, 지금까지 들은 학점, 유지해야 하는 성적(GPA)을 학교 포털 여러 메뉴에서 따로 확인해야 한다. 특히 유학(D-2) 비자는 **일정 학점 이상 이수**와 **학사경고·낮은 성적**이 비자 연장과 자격 유지에 영향을 줄 수 있어, 단순 성적 확인을 넘어 "지금 내 학업 상태가 안전한가"를 알기 어렵다.

UniMate의 수강 & 학업 기능은 사용자의 학업 현황(이수 학점, 졸업 요건, GPA, 학기)을 한 화면에 모아, 졸업까지 남은 양과 유학생이 특히 주의해야 할 수강 요건을 쉬운 언어로 보여준다.

## 2. 목표

1. 사용자가 현재 이수 학점, 졸업 필요 학점, 남은 학점을 한곳에서 확인할 수 있다.
2. 현재 GPA와 유학생이 유지해야 하는 기준(경고 구간)을 함께 보여준다.
3. 현재 학기와 학년, 전공 정보를 요약해서 표시한다.
4. 졸업까지의 진척도를 시각적인 진행 바로 보여준다.
5. 유학생 수강 관련 핵심 요건(최소 이수 학점, 성적 경고)을 쉬운 설명으로 제공한다.
6. 홈 화면과 통합 검색에서 수강 & 학업 화면으로 자연스럽게 이동할 수 있다.

## 3. 비목표

MVP에서는 다음 항목을 구현 범위에 포함하지 않는다.

- 학교 포털·학사 시스템 실시간 연동 및 로그인
- 수강신청·장바구니·시간표 편성 (시간표는 별도 `prd-timetable.md`)
- 과목별 성적 입력·수정 및 성적 산출
- 학기별 성적표(transcript) 상세 조회
- 수강 가능 과목 추천, 졸업 요건 자동 판정(세부 영역별 학점)
- 비자 연장 자동 판정 (FD1 영역과 연계는 후속 단계)

## 4. 주요 사용자

- 졸업까지 남은 학점과 학기를 가늠하려는 유학생
- 비자 유지를 위해 성적·이수 학점 기준을 신경 써야 하는 유학생
- 자신의 학업 현황을 한국어 포털 없이 쉬운 언어로 확인하려는 학생

## 5. 핵심 사용자 시나리오

### 시나리오 A: 졸업까지 남은 학점 확인

1. 사용자가 홈의 학업 카드 또는 왼쪽 메뉴에서 수강 & 학업을 선택한다.
2. 이수 학점(92), 졸업 필요 학점(130), 남은 학점(38)이 진행 바와 함께 표시된다.
3. 사용자는 몇 학기 더 다녀야 하는지 대략 가늠한다.

### 시나리오 B: 성적 상태 확인

1. 사용자가 현재 GPA(3.42)와 기준선을 본다.
2. 경고 구간(예: 평점 미달 또는 학사경고)에 해당하는지 색상과 문구로 알려준다.
3. 안전하면 안심, 위험하면 어떤 조치가 필요한지 안내한다.

### 시나리오 C: 유학생 수강 요건 확인

1. 사용자가 "유학생 수강 요건" 섹션을 연다.
2. 학기당 최소 이수 학점, 성적 유지 기준 등 핵심 요건이 쉬운 설명으로 표시된다.
3. 각 요건에 최종 확인 출처(국제처·학칙)가 함께 표시된다.

## 7. 화면 및 반응형 요구사항

### 데스크톱

- 상단에 졸업 진척도 진행 바와 핵심 수치(이수/필요/남은 학점) 카드를 가로로 배치한다.
- GPA 카드는 숫자와 기준선, 상태 배지(안전/주의/경고)를 함께 표시한다.
- 하단에 유학생 수강 요건 목록을 카드 또는 아코디언으로 표시한다.

### 모바일·태블릿

- 진척도 바를 상단에 두고, 수치 카드는 세로로 쌓는다.
- GPA·학적 요약은 접을 수 있는 섹션으로 공간을 절약한다.
- 긴 요건 설명은 줄바꿈되어도 읽을 수 있어야 한다.

### 공통

- 학점·GPA는 소수점 표기를 일관되게 한다(GPA 소수점 둘째 자리).
- 경고 상태는 FD1과 동일한 색 규칙(red/yellow/blue)을 재사용한다.
- 데이터 요청 중에는 레이아웃 크기를 유지하는 스켈레톤을 표시한다.

## 8. 데이터 및 API 계약

### 요청

`GET /api/academics`

- 쿼리 파라미터 없음(MVP는 데모 사용자 기준, `backend/data/demo-user.json`).
- 후속 단계에서 사용자 식별자를 추가한다.

### 응답

```ts
type AcademicStatus = "safe" | "warning" | "danger";

interface AcademicsResponse {
  profile: {
    name: string;
    university: string;
    department: string;
    year: number;
    semester: string;      // "2026학년도 2학기 (6번째 학기)"
    status: string;        // "외국인 유학생, 학부 재학"
  };
  credits: {
    earned: number;        // 92
    required: number;      // 130
    remaining: number;     // required - earned, 음수면 0
    progress: number;      // 0~100 (반올림 정수)
  };
  gpa: {
    value: number;         // 3.42
    scale: number;         // 4.5
    status: AcademicStatus;
    /** 경고 기준 (학칙·국제처 기준값) */
    warningBelow: number;  // 예: 2.0
  };
  requirements: AcademicRequirement[];
  /** 모든 수치는 최종 확인 필요 */
  disclaimer: string;
  sources: { label: string; url: string }[];
}

interface AcademicRequirement {
  id: string;
  title: string;           // "학기당 최소 이수 학점"
  summary: string;         // 쉬운 언어 설명
  status: AcademicStatus;  // 현재 사용자가 충족하는지
}
```

- `credits.progress`는 `round(earned / required * 100)`, 상한 100.
- `gpa.status`는 `value < warningBelow`면 `danger`, 근접(예: `< warningBelow + 0.3`)이면 `warning`, 그 외 `safe`.
- 계산은 순수 함수로 분리하고, 기준값(졸업 학점·GPA 경고선)은 설정 파일 한 곳에서만 바꾼다(FD1 `config.ts` 패턴 참고).

## 9. 오류 및 예외 처리

- API 연결 실패: 오류 메시지와 `다시 시도` 버튼을 표시한다.
- 필수 필드 누락(이수 학점·필요 학점 없음): 해당 카드에 `정보 없음`을 표시하고 나머지는 정상 표시한다.
- `required`가 0 이하: 진행 바를 숨기고 수치만 표시한다(0 나눗셈 방지).
- GPA 미제공: GPA 카드에 `성적 정보 없음`을 표시한다.
- 비자 규정과 마찬가지로 수치는 참고용임을 명확히 하고, 공식 판정은 국제처·포털로 안내한다.

## 10. 성공 지표

- 수강 & 학업 화면 진입 후 첫 결과 표시 성공률 99% 이상
- 홈 축약 카드에서 전체 화면으로의 이동률
- 수강 요건 섹션 펼침 비율(유학생이 요건을 실제로 확인하는지)
- 오류 발생 후 재시도 성공률

## 11. MVP 승인 기준

- [ ] 홈과 왼쪽 메뉴에서 `/academics`로 이동할 수 있다.
- [ ] 이수/필요/남은 학점과 졸업 진척 바를 데모 데이터로 표시한다.
- [ ] GPA와 경고 상태(안전/주의/경고)가 색상으로 구분된다.
- [ ] 학년·학기·전공·재학 상태 요약이 표시된다.
- [ ] 유학생 핵심 수강 요건이 설명·출처와 함께 표시된다.
- [ ] 로딩, 정보 없음, 오류 및 재시도 상태가 존재한다.
- [ ] 모든 수치에 "최종 확인은 포털·국제처" 안내가 보인다.
- [ ] `npm run check`(백엔드 타입체크+테스트, 프론트 타입체크)와 ESLint를 통과한다.

## 12. 후속 단계

1. 학교 포털·학사 시스템 연동으로 실제 사용자 학업 데이터 반영
2. 세부 영역별(전공·교양·일반선택) 졸업 요건 판정
3. 학기별 성적표 및 과목별 성적 조회
4. FD1(비자) 영역과 연계: 수강 요건 미충족 시 비자 자격 경고
5. 수강신청 시기 알림 및 추천 과목
6. 다국어(ko/en/uz) 문구 지원 (FD1 guides 패턴 재사용)
