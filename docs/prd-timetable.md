# PRD: 시간표

- 문서 상태: MVP 구현 기준
- 작성일: 2026-10-03
- 제품: UniMate (유학생 행정비서)
- 담당 영역: 주간 수업 일정 확인

## 1. 배경과 문제

외국인 유학생은 수업 시간, 강의실, 교수 정보를 학교 포털에서 반복해서 찾아야 한다. 포털 접근이 불편하거나 한국어 메뉴가 익숙하지 않으면 강의실 변경과 수업 시간을 놓칠 가능성이 커진다.

UniMate의 시간표 기능은 한 주의 수업을 요일별로 보여주고, 데스크톱과 모바일에서 같은 정보를 빠르게 확인할 수 있게 한다.

## 2. 목표

1. 월요일부터 금요일까지의 수업을 한 화면에서 확인할 수 있다.
2. 각 수업의 시간, 과목명, 과목 코드, 강의실, 교수 정보를 제공한다.
3. 이전 주, 다음 주, 이번 주로 이동할 수 있다.
4. 현재 날짜와 선택한 모바일 요일을 명확하게 표시한다.
5. 로딩·오류·수업 없음 상태를 명확하게 제공한다.

## 3. 비목표

MVP에서는 다음 항목을 구현 범위에 포함하지 않는다.

- 사용자의 학교 포털 계정 연동
- 수업 추가·수정·삭제 및 시간표 편집
- 학기 선택과 개인별 시간표 영구 저장
- 휴강·보강·강의실 변경 실시간 알림
- Google Calendar 또는 iCal 내보내기
- 과제, 시험, 출석 정보 관리

## 4. 주요 사용자

- 이번 주 수업 시간과 강의실을 빠르게 확인하려는 학생
- 모바일에서 오늘 수업만 간단히 확인하려는 학생
- 다음 주 일정까지 미리 확인하려는 학생

## 5. 핵심 사용자 시나리오

### 시나리오 A: 이번 주 전체 시간표 확인

1. 사용자가 홈의 시간표 카드 또는 왼쪽 메뉴를 선택한다.
2. 현재 주 월요일부터 금요일까지 수업이 표시된다.
3. 오늘 날짜는 별도 강조 표시된다.
4. 사용자는 각 수업의 시간, 강의실과 교수를 확인한다.

### 시나리오 B: 다른 주 확인

1. 사용자가 이전 또는 다음 화살표를 선택한다.
2. 기준 월요일이 7일 단위로 변경된다.
3. 해당 주의 시간표를 다시 요청하고 로딩 상태를 표시한다.
4. `이번 주` 버튼으로 현재 주에 즉시 돌아온다.

### 시나리오 C: 모바일에서 특정 요일 확인

1. 모바일 화면에서는 월~금 요일 탭을 표시한다.
2. 사용자가 요일을 선택한다.
3. 선택한 요일의 수업만 세로 목록으로 표시한다.
4. 수업이 없으면 빈 상태 메시지를 표시한다.

## 7. 화면 및 반응형 요구사항

### 데스크톱

- 월~금 5개 열을 동시에 표시한다.
- 열 머리글에 요일과 날짜를 표시한다.
- 각 수업 카드는 색상, 시간, 과목, 장소, 교수 정보를 포함한다.
- 오늘인 열은 머리글과 `오늘` 배지로 강조한다.

### 모바일·태블릿

- 좁은 화면에서는 5열 시간표 대신 요일 탭을 표시한다.
- 선택된 요일은 강조하고, 수업을 세로 카드로 표시한다.
- 강의실과 교수 정보가 줄바꿈되더라도 읽을 수 있어야 한다.

### 공통

- 주간 범위는 사용자가 이해하기 쉬운 한국어 날짜 형식으로 표시한다.
- 현재 주를 보고 있을 때 `이번 주` 버튼을 비활성화한다.
- 데이터 요청 중에는 기존 레이아웃 크기를 유지하는 스켈레톤을 표시한다.

## 8. 데이터 및 API 계약

### 요청

`GET /api/schedule?week=YYYY-MM-DD`

- `week`은 표시할 주의 월요일 날짜다.
- 값이 없으면 서버가 현재 주 월요일을 사용한다.
- 형식이 잘못되면 HTTP 400과 사용자에게 표시 가능한 `message`를 반환한다.

### 응답

```ts
interface ScheduleResponse {
  weekStart: string
  days: ScheduleDay[]
}

interface ScheduleDay {
  dayOfWeek: number // 1(월) ~ 5(금)
  date: string      // YYYY-MM-DD
  classes: ScheduleClass[]
}

interface ScheduleClass {
  id: number
  dayOfWeek: number
  startTime: string // HH:mm
  endTime: string   // HH:mm
  courseCode: string
  courseName: string
  professor: string
  room: string
  color: 'blue' | 'green' | 'yellow' | 'red' | 'purple'
}
```

## 9. 오류 및 예외 처리

- API 연결 실패: 오류 메시지와 `다시 시도` 버튼을 표시한다.
- 수업이 없는 요일: 해당 요일 열 또는 모바일 목록에 `수업 없음`을 표시한다.
- 잘못된 `week`: API는 HTTP 400을 반환한다.
- 토·일요일 접근: 기본 모바일 선택 요일은 월요일로 설정한다.
- 주 이동 중: 새 응답을 받을 때까지 스켈레톤을 표시한다.
- 현재 주 재선택: 이미 현재 주라면 `이번 주` 버튼을 비활성화한다.

## 10. 성공 지표

- 시간표 화면 진입 후 첫 결과 표시 성공률 99% 이상
- 주 이동 후 결과 표시 시간 1초 이내(로컬 API 기준)
- 홈 시간표에서 전체 시간표 화면으로의 이동률
- 모바일 요일 탭 사용 후 수업 정보 확인 성공률
- 오류 발생 후 재시도 성공률
