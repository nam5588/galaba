# K-Campus Pass — FD1 PRD: 체류·건강보험 필수 일정

Oct 3, 2026 · @Muhammad

## 개요

FD1은 유학생의 **외국인등록, 체류기간 연장, 건강보험 납부** 일정을 자동으로 계산하고, 마감 전에 모국어로 알려 주는 기능입니다.

한 줄 정의: **"날짜 두 개만 넣으면, 비자와 보험 마감은 앱이 챙깁니다."** (입국일 + 체류만료일)

목표는 세 가지입니다.

1. 등록·연장 마감을 놓쳐 과태료를 내는 유학생을 0에 가깝게 줄인다.
2. 건강보험 체납으로 병원 혜택 제한이나 연장 불이익을 받는 일을 막는다.
3. "내가 지금 해야 할 행정 일은 무엇인가"를 한 화면에서 보여 준다.

## 문제와 대상

행정 정보는 하이코리아, 건강보험공단, 학교 국제처 공지에 한국어로 흩어져 있습니다. 유학생은 마감일을 직접 계산해야 하고, 이사나 여권 갱신 같은 사건이 생길 때마다 마감이 새로 생깁니다.

| 사용자 | 상황 | 가장 큰 불편 |
| --- | --- | --- |
| 신입 유학생 (처음 입국) | 90일 안에 등록해야 하는 것을 모름 | 하이코리아 예약이 빨리 차서 기한을 넘김 |
| 재학생 (D-2) | 매년 연장, 매월 보험료 | 연장 가능 날짜, 필요 서류를 헷갈림 |
| 이사한 학생 | 기숙사 → 원룸 | 14일 안에 체류지 변경 신고를 모름 |

주 고객은 국민대 외국인 유학생 2,000명 이상입니다. 구조는 다른 대학에도 그대로 적용됩니다.

| 건강보험료 | 2026년 월 79,320원, 매월 25일까지 납부 | - | [성신여대](https://sungshin.ac.kr/bbs/main_eng/4941/152421/artclView.do) |
| 보험료 체납 | 다음 달 1일부터 병원 혜택 제한, 연장 시 체류기간 제한 | 혜택 없음 + 연장 불이익 | [인하대](https://internationalcenter.inha.ac.kr/bbs/internationalcenter/2507/146572/artclView.do), [데일리팜](https://m.dailypharm.com/user/news/86232) |

## 기능 요구사항

| ID | 기능 | 동작 | 우선순위 |
| --- | --- | --- | --- |
| FD1-1 | 외국인등록 마감 | 입국일 입력 → 마감일(+90일)과 D-day 표시. 서류 체크리스트와 하이코리아 예약 링크 제공 | P0 |
| FD1-2 | 체류기간 연장 | 만료일 입력(또는 ARC 사진 OCR) → 신청 가능일(만료 4개월 전)부터 만료일까지 단계별 알림. 서류 체크리스트 제공 | P0 |
| FD1-3 | 건강보험 자동 추적 | 가입일(=등록일)부터 매월 79,320원을 자동으로 더해 "지금까지 낼 돈 / 남은 돈" 표시 | P0 |
| FD1-4 | 납부 알림과 체크 | 매월 20일 알림, 25일 마감 알림. "납부했어요" 버튼으로 체크하고, 미납 개월 수를 빨간색으로 표시 | P0 |
| FD1-5 | 모국어 설명 | 모든 알림과 체크리스트를 선택 언어로 표시 (우즈벡어, 영어, 베트남어 등) | P0 |
| FD1-6 | 체류지 변경 | "이사했어요" 버튼 → 14일 마감 자동 생성 + 건강보험 주소 변경 알림 | P1 |
| FD1-7 | AI 질문 | "연장할 때 뭐가 필요해?, 어디에서 발급해야 돼?" 같은 질문에 규정 문서 기반으로 모국어 답변 | P1 |
| FD1-8 | 납부확인서 업로드 | 영수증 사진을 올리면 AI가 금액·월을 읽고 자동 체크 | P1 |

건강보험 화면 예시: **"가입 8개월째 · 납부 634,560원 · 미납 0개월 · 다음 납부 10월 25일"**

## 사용자 흐름

온보딩은 1분 안에 끝나고, 그 뒤로는 알림이 알아서 옵니다.

1. 언어 선택 (우즈벡어 / English / 한국어 ...)
2. 비자 종류 선택 (D-2, D-4)
3. 입국일 입력
4. 외국인등록증이 있는지 선택
   1. 없음 → FD1-1 등록 마감 카드 생성
   2. 있음 → 등록일과 체류만료일 입력 (또는 ARC 사진 촬영)
5. 홈 화면 = "지금 해야 할 일" 카드 목록, 마감 가까운 순서
6. 카드 클릭 → 모국어 설명 + 서류 체크리스트 + 신청 링크
7. 완료 버튼 → 다음 주기 일정 자동 생성 (예: 연장 완료 → 새 만료일 입력 요청)

## 데이터 모델과 알림 규칙

사용자가 넣는 날짜는 세 개뿐이고, 나머지 일정은 모두 계산됩니다.

```
User {
  language: "uz" | "en" | "ko" | ...
  visaType: "D-2" | "D-4"
  entryDate: Date            // 입국일
  arcIssuedDate?: Date       // 등록일 = 건강보험 가입일
  stayExpiryDate?: Date      // 체류만료일
}

Task {
  userId, type: "ARC_REGISTER" | "ARC_EXTEND" | "NHIS_PAY" | "ADDRESS_CHANGE"
  dueDate: Date, openDate?: Date, status: "TODO" | "DONE"
}

InsurancePayment {
  userId, month: "2026-10", amount: 79320, paid: boolean, paidAt?: Date
}

Config { nhisMonthlyFee: 79320, nhisDueDay: 25, ... }  // 매년 갱신
```

| 일정 | 알림 시점 |
| --- | --- |
| 외국인등록 (입국 +90일) | 입국 직후, D-30, D-14, D-7, D-1 |
| 체류기간 연장 | 만료 4개월 전(신청 가능), D-60, D-30, D-14, D-7, D-1 |
| 건강보험 납부 | 매월 20일, 25일. 미납이면 다음 달 1일 "병원 혜택 제한" 경고 |
| 체류지 변경 (이사일 +14일) | 이사 당일, D-7, D-1 |

알림 채널은 웹 푸시와 텔레그램/카카오톡 중 하나로 시작합니다. 매일 1회 스케줄러(cron)가 Task를 확인해 보냅니다.

## MVP 범위, 지표, 리스크

데모는 FD1-1~5만 보여 줍니다. 가상의 유학생이 날짜 세 개를 넣으면 홈 화면에 카드가 생기고, 우즈벡어 알림이 오는 장면이 핵심입니다.

성공 지표

- 온보딩 완료율 80% 이상, 완료 시간 1분 이내
- 가입자 중 등록·연장 마감을 놓친 비율 0%
- 건강보험 미납 개월 수 감소 (가입 전과 비교)

| 리스크 | 대응 |
| --- | --- |
| 규정이나 보험료가 바뀜 | 숫자는 Config로 분리, 학기마다 국제처 공지로 검수 |
| 잘못된 안내로 불이익 발생 | 모든 화면에 "최종 확인은 하이코리아·1345" 안내와 출처 링크 |
| 개인정보 (ARC 사진) | 등록번호는 저장하지 않고 날짜만 추출 |
| 납부 여부를 자동으로 모름 | MVP는 수동 체크, 이후 영수증 OCR (FD1-8) |
